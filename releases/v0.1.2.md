## What's new

- Faster cleanup with a single batched browsing-data request.
- Choose the last hour, 24 hours, 7 days, 30 days, or all time.
- Improved popup and settings pages with light/dark themes and keyboard focus indicators.
- Prevent duplicate cleanup requests and handle preference and cleanup failures.
- Remove the unused context-menu permission and clarify Chrome Sync behavior.
- Repair automated releases: test, validate the version, package runtime files, and verify uploaded assets before publishing.

## Install or update

1. Download **dalex-chrome-cleaner-v0.1.2.zip** below and extract it to a permanent folder.
2. Open `chrome://extensions/` and enable **Developer mode**.
3. Choose **Load unpacked** and select the extracted folder containing `manifest.json`.
4. To update an existing unpacked installation, replace its files and click **Reload** on the extension card.

Requires Chrome 96 or later. This is an unpacked extension ZIP, not a Chrome Web Store release. Clearing browsing data cannot be undone; clearing cookies may sign you out of websites.

`SHA256SUMS.txt` contains the installation ZIP's SHA-256 checksum. Source code is available through GitHub's automatic source archives.
